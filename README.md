## Objetivo
Aplicação de conceitos e técnicas de Inteligência Artificial para mitigar a evasão de clientes (Churn Rate) de empresas de telecomunicações. 

Utilizando a opção **Framework** (Python + *scikit-learn*), o projeto visa desenvolver um modelo de classificação capaz de prever matematicamente a probabilidade de um cliente cancelar seus serviços de telecomunicações. 

## Tecnologias Utilizadas
* **Linguagem:** Python
* **Manipulação de Dados:** Pandas, NumPy
* **Visualização:** Matplotlib, Seaborn
* **Machine Learning (Preparação):** Scikit-Learn (*MinMaxScaler*, *One-Hot Encoding*)
